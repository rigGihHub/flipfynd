# FlipFynd v0.11.60 – Comp Relevance Integrity

- EXACT comps kräver nu att alla kända identitetsfält matchar; saknat set eller säsong får inte längre passera som exakt.
- Variant, serienämnare, auto/patch och gradering hålls isär så premiumskillnader inte blandas.
- En comp med extra premiumegenskap kan inte vara exakt för ett rått/base-mål.
- Premium Comp Hunter kräver nu verifierad sold-evidens via samma sold-quality-gate som övrig exact-comp-logik.
- Near comps får fortfarande visas som kontext men får inte låsa upp exakt/premium värderingsstöd.
- Inga nya priser, comps eller marknadsvärden uppfinns.
