# FlipFynd v0.12.41 — Visual Checklist Matcher

Bilddetaljer matchas nu mot den källstyrda kort-/checklistkunskapen. Namngivna varianter och program kan få strukturellt stöd från officiella källor, och synlig serialisering jämförs med dokumenterad print run. Konflikter, exempelvis `/99` mot dokumenterad `/25`, visas uttryckligen. Checklistmatch verifierar inte spelare, kortnummer eller autenticitet och får aldrig ensam påverka värdering eller KÖP.
