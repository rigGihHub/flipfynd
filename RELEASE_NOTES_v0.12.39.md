# FlipFynd v0.12.39 — Card Identity Explainer

- Förklaringsknappen på varje annons börjar nu med **Vad är det här för kort?**.
- Visar spelare, set/program, säsong/år, kortnummer, variant/parallel, numrering, rookie/RC-status och verifierade specialegenskaper.
- Identitetsstatus från Exact Identity Gate visas tydligt, inklusive om kortet är tillräckligt säkert identifierat för exact-comp-sökning.
- Okända uppgifter visas som **Ej säkert identifierat** i stället för att gissas från rubriken.
- En rookie-signal får inte förvandlas till ett påstått officiellt rookieår utan verifiering.
- Regressionstester tillagda för identitetssammanfattningen.
- Version uppdaterad till v0.12.39.
