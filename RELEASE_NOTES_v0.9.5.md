# FlipFynd v0.9.5 – Dynamic Max Bid

- Ny Dynamic Max Bid-motor ovanpå Exact Comp Hunter + Comp Verdict.
- Dynamic Max Bid får aldrig skapa ett budtak från comps och får aldrig höja det befintliga FlipFynd-taket.
- Minst ett Comp Verdict som uttryckligen stödjer säkert maxbud krävs.
- Mycket starkt, färskt och tätt exact-comp-underlag behåller upp till 98 % av det befintliga riskjusterade taket.
- Svagare men fortfarande godkänt exact-comp-underlag ger större säkerhetsmarginal.
- Medianen för exakta sålda comps används som ett andra säkerhetsankare och kan sänka taket ytterligare.
- UI visar ordinarie FlipFynd-tak kontra Dynamic Max Bid och förklarar varför taket eventuellt sänkts.
- Ingen comp får ensam skapa värde, vinst, ROI eller köpbeslut.
