# DATA RESEARCH v0.10.0 – Card Knowledge Library

Den här releasen omstrukturerar den befintliga officiellt grundade kunskapsbanken till familjer som FlipFynd kan resonera över på ett säkrare sätt.

## Ny modell

Kunskapsbiblioteket bygger relationen:

**produktfamilj → programfamilj → variant → dokumenterad print run**

Exempel som nu blir sammanhängande familjer:

- Upper Deck Series → Young Guns → Young Guns / Deluxe /250 / Exclusives /100 / High Gloss /10 / Clear Cut.
- Skybox Metal Universe → Precious Metal Gems → PMG / Red /100 / Green /10 / Gold 1/1.
- O-Pee-Chee Platinum → OPC Platinum Parallels → Violet Pixels /299 / Seismic Gold /50 / Orange Checkers /25 / Emerald Surge /10.
- SP Authentic → Future Watch → Future Watch Autograph /999 / Auto Patch /100 / Black Auto Material 1/1.
- Prizm Football → parallell- och chasefamiljer som Black 1/1, Genesis, White Tiger, Color Blast, Downtown och Manga.
- Topps Chrome UEFA, Topps Merlin UEFA, The Cup, Black Diamond, Artifacts och Stature behåller sina verifierade programstrukturer.

## Säkerhetsprincip

Ett syskonkort i samma familj är **inte** en exact comp. Biblioteket används för att upptäcka att två kort är relaterade men olika. Print run, kortnummer, säsong, program och parallel måste fortfarande matchas enligt Comp Match Guardrails.

Kunskapsbiblioteket innehåller inga priser eller prisfaktorer och får inte höja värde, ROI, vinst eller maxbud.
