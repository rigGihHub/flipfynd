# FlipFynd v0.2.0 – Foundation

## Ändrat
- Ny branding i Streamlit: FlipFynd.
- Korrigerad kommentarlogik så kommentaren använder samma analysvärden som resultatet.
- Korrigerad hantering av blended comp-källa i kommentarer.
- Korrigerad ordning för varning vid höga inköpskostnader.
- Fylld `requirements.txt` med projektets externa Python-beroenden.
- Tydligare felinformation när Tradera-hämtning misslyckas.

- Större UX-förenkling av startsida/resultatkort (planerat till nästa UX-release).
