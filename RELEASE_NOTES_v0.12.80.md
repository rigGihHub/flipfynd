# FlipFynd v0.12.80 – Reference-Image Verification

- Ny research-only referensverifiering för kuraterade oddity/error-kort.
- Kända kort får konkreta A/B/C-kännetecken för jämförelse mot dokumenterad variant och normalversion.
- Visuell identitet ensam får inte räcka: variant-specifik bildsignal krävs för stark referensmatch.
- Vanliga skador/produktionsfel cappar matchscore och kan aldrig skapa variantpremie.
- UI visar referensmatch, variantkännetecken, normalversion och exakt nästa verifieringssteg.
- Inga upphovsrättsskyddade referensbilder bäddas in; systemet lagrar endast beskrivna kännetecken och kräver auktoritativ extern referens vid slutverifiering.
- Referensmatch får aldrig skapa exact identity, SOLD-comp, marknadsvärde, maxpris eller KÖP.
