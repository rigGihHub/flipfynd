# FlipFynd v0.13.8

- Inför ett separat kortmeritfilter före Seller Top 5-rankningen.
- Vanliga Match Attax-, Adrenalyn- och stickerkort utan verifierad variant används inte som utfyllnadsfynd.
- Signature Style, Silver Script och tryckta/faksimilsignaturer får inget autograf- eller premiumlyft.
- Spelarens kändisskap kan inte ensamt göra ett kort till fyndkandidat.
- Top 5-panelen finns alltid, men tomma platser visas öppet när färre än fem kort klarar kvalitetsgränsen.
