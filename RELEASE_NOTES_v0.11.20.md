# FlipFynd v0.11.20 – Flip Velocity

- Adds a conservative Flip Velocity signal based on verified sold-comps turnover.
- Shows an approximate turnover band and normalized profit pace (kr/30 days) when evidence supports it.
- Asking-only and heuristic market data cannot manufacture a selling-time estimate.
- The metric is explicitly a prioritisation signal, not a promise that a card will sell within a given number of days.
- UI surfaces Flip Velocity directly on result cards.
