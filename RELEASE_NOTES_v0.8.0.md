# FlipFynd v0.8.0 – Edge Engine

- Ny marknadsedge 0–100 som förklarar *varför* en annons kan vara missad, inte bara om priset ser lågt ut.
- Kombinerar sökbarhetsbrister, informationsgap, annonskvalitet kontra identifieringsstyrka och säljarens rubrikmönster.
- Säljarkontext byggs från aktuellt inläst Tradera-underlag: antal annonser och andel generiska kortrubriker.
- Ny panel **⚡ Edge Engine** prioriterar annonser där FlipFynd bedömer att köparen kan ha en informationsfördel.
- Hög analysrisk begränsar edge-poängen.
- Edge får aldrig skapa marknadsvärde, vinst, ROI, maxbud eller KÖP-beslut.
