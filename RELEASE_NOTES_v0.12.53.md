# FlipFynd v0.12.53 – Same-Seller Add-On Advisor

- Bygger vidare på Same-Seller Basket Hunter med automatisk klassning per extra kort: **LÄGG TILL I SAMMA PAKET**, **MÖJLIGEN** eller **HOPPA ÖVER**.
- Ett extra kort får bara automatisk add-on-rekommendation när det redan står på egna meriter: analyserat, KÖP, tillräcklig identitet, minst en SOLD-comp och rimlig fyndpotential.
- Oanalyserade kort markeras alltid som analysera först.
- Delad frakt får aldrig ensam förvandla ett svagt kort till ett fynd.
- UI visar kort motivering direkt under varje annons hos samma säljare.
