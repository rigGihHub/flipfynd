# FlipFynd v0.12.42 – Visual Exact Identity Resolver

- Ny `src/visual_exact_identity.py` väger ihop fram-/baksidesfynd, annonstext, observerad historik och checklist-/variantstruktur.
- Visar **Mest sannolika exakta kort** med kombinerad identitetsscore och alternativa kandidater.
- Konflikt mellan synlig print run/variant och dokumenterad checkliststruktur blockerar exakt identitet.
- Visar konkreta nästa verifieringssteg när kortnummer, set eller år saknas.
- Exact Comp Hunter låses bara upp när huvudkandidaten har oberoende stöd och inga checklistkonflikter.
- Ingen bild- eller checklistmatch får ensam skapa marknadsvärde, ROI eller KÖP.
