# FlipFynd v0.11.78 – Portfolio Concentration Transparency

- “Mina pengar” visar nu faktisk kapital-koncentration i den valda köpkorgen.
- Visar största enskilda positionens andel och de två största positionernas sammanlagda andel.
- Bryter ned kapitalet per spelare, set/program och sport när dessa fält finns i analysen.
- Okänd spelare eller okänt set visas öppet som okänd exponering i stället för att gissas.
- Visar alla enskilda positioners kapitalandel.
- Inga fasta koncentrationsgränser införs.
- Ingen “låg/medel/hög risk”-etikett skapas.
- Koncentrationsvyn ändrar inte portföljval, Top 3, KÖP-beslut eller maxpris.
