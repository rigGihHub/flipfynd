# FlipFynd v0.11.91 – Shipping on Listing Cards

- Fraktkostnad visas direkt på annons-/resultatkorten.
- Känd Tradera-frakt visas som `Frakt X kr`.
- Om frakten inte kunnat läsas säkert visas kalkylantagandet tydligt som `Antagen frakt 29 kr` / `29 kr*`, aldrig som verifierad frakt.
- Gäller nybörjarens köpvy, Bästa tillgängliga, Slutar snart och den fulla resultatlistan.
- Ingen köp-, ranking-, värderings- eller maxprislogik ändras.
