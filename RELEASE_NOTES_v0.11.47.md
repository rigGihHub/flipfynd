# FlipFynd v0.11.47 – Model Correction Candidates

- Omvandlar tillräckligt tydliga verkliga segmentfel till manuella granskningskandidater.
- Nettovinst: reagerar först vid medianfel minst 25 kr.
- ROI: reagerar först vid medianfel minst 10 procentenheter.
- Säljtid: reagerar först vid medianfel minst 7 dagar.
- Minst 5 utfall krävs; 10+ och flera samtidiga felsignaler krävs för Stark kandidat.
- Förslagen säger vilken del som bör granskas men räknar inte fram eller applicerar en godtycklig haircut.
- Inga automatiska modell-, ranking- eller köpbeslutsändringar.
