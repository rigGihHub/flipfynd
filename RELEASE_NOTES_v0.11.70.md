# FlipFynd v0.11.70 – Error Metric Integrity

- Tar bort dimensionsmässigt felaktig gemensam severity över SEK, ROI-procentenheter och säljdagar.
- Error Segmentation rangordnar nu vinstfel, ROI-fel och säljtid separat.
- Den generiska segmentlistan har stabil, icke-severity-baserad ordning.
- Model Correction Candidates lagrar separata felstorlekar per måttenhet och saknar gemensam severity.
- Kandidatordning baseras inte längre på storleken hos inkommensurabla mått.
- UI visar största typiska fel separat för Vinst (kr), ROI (%-enheter) och Säljtid (dagar).
- Inga automatiska modell-, värderings- eller KÖP-ändringar.
