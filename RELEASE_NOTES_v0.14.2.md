# FlipFynd v0.14.2

- Bildgranskaren analyserar upp till åtta bilder och redovisar varje bild separat.
- Läser fram-/baksida, närbilder, slab-etikett, certifikatnummer och tillverkarlogotyp när de faktiskt syns.
- Inför visuell köpstoppskontroll för konflikter, tryckt/faksimilsignatur, låg bildsäkerhet och möjlig manipulation.
- Bilder kan stoppa fortsatt köpkontroll men kan aldrig ensamma skapa värdering eller fyndstatus.
- Visar tydligt vilka bilder eller detaljer som fortfarande saknas.
