# FlipFynd v0.11.82 – Stjärnskott Radar

- Ny faktisk Stjärnskott Radar-vy i appen.
- Strukturerad JSON-evidens går via befintlig Momentum Source Intake; ogiltiga poster avvisas.
- Radar kombinerar dokumenterade momentumhändelser med redan skannade annonser via strukturerat `player_name`.
- Visar källa, datum, händelsetyp, källbredd, kort, total kostnad, befintligt beslut, identitetsstatus, Exact SOLD-evidens och sellability när datan finns.
- Marknadsreaktion visas uttryckligen som ej verifierad tills tidsmässigt jämförbar SOLD-data finns.
- Momentum kan inte skapa KÖP eller ändra värdering/maxbud.
